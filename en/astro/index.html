FAQ

Common questions

Can Astro run a store?

Yes. Astro handles the site. Commerce can live on Medusa, Shopify or another engine.

Does the page ship without JavaScript?

Astro sends JavaScript on the components that need to run in the browser. The rest of the page stays HTML.

Can the team keep the components it already has?

Yes. React, Vue, Svelte and other libraries come in as islands inside the Astro page.
