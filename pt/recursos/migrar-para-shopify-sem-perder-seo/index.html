Migrar para Shopify sem perder SEO: checklist

Checklist para migrar para Shopify sem perder SEO: mapa de URLs, redirects 301, metas, sitemap e Search Console.

Falar com a 27n Queres aplicar isto ao teu projeto?

O ranking não se perde porque mudaste de plataforma. Perde-se quando URLs antigas viram 404. O plano:

  1. Exportar URLs com tráfego (Search Console + sitemap + analytics).
  2. Mapear cada URL antiga para o equivalente Shopify (/products/, /collections/, /pages/).
  3. Importar redirects 301 antes do go-live.
  4. Transferir títulos e meta descriptions relevantes.
  5. Enviar o novo sitemap e monitorizar 90 dias.

Detalhes por plataforma: WooCommerce, Magento, PrestaShop.
